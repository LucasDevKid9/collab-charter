# 示例一：一次请求的完整管线轨迹

命令：

```bash
PYTHONPATH=src python3 -m collab_charter.cli handle "帮我把这个模块重构成可测试的结构" \
  --constraint "保持API兼容" --plan
```

真实输出：

```text
── 路由 ──
Route(全量): 安全闸门 → 意图解析 → 认知镜像 → 记忆检索 → 角色协作 → 综合裁决 → 输出 → 反馈回流
（启用全量路由：任务涉及多步计划）

── 逐站轨迹 ──
[ok ] 安全闸门：裁决 1 条流，无拦截
[ok ] 意图解析：显性/隐含诉求拆解：指令流×1
[ok ] 认知镜像：认知镜像：我理解你要的是「帮我把这个模块重构成可测试的结构」，对吗？
[ok ] 记忆检索：激活 0 条记忆流
[ok ] 角色协作：三角视角并行：建构者1项 / 质疑者1项 / 验证者1项
[ok ] 综合裁决：裁决 0 次冲突，保留 1 条
[ok ] 输出：按 0.7 只呈现必要信息，输出 1 条流
[stop] 反馈回流：未完成回流，系统处于开环（0.3-I1）

── 输出 ──
- [结论] 帮我把这个模块重构成可测试的结构

── 认知镜像 ──
我理解你要的是「帮我把这个模块重构成可测试的结构」，对吗？

── 自检未通过 ──
回流前自检未通过（0.8）：
- 0.8-C1 关键约束是否丢失？ —— 未在输出中体现：['保持API兼容']
- 0.8-C4 反馈是否已回流、记忆是否已更新？ —— 会话尚未完成记忆回流（0.3 第 8 站）
```

## 这个输出在说什么

**① 路由决策是有理由的，不是黑箱。**
`--plan` 声明了这是多步计划，按 0.9 触发全量路由，理由被打印出来。
如果去掉 `--plan`、把任务说成"快速看一下"，就会走三站最小管线。

**② 第 3 站认知镜像自动生成了复述话术。**
`我理解你要的是「…」，对吗？` 这正是宪章 3-R3 要求的"先声明理解，再动手"，
且是 0.3-I2 的强制节点——但走快速通道时会自动跳过，避免把协议变成前置仪式。

**③ 第 5 站三角视角被正确标为内部流。**
建构者/质疑者/验证者三条流都带 `internal_only` 标记，因此**不出现在输出里**
（0.7-R1：内部冗长流默认不展示）。用户说「讲思路」时可展开。

**④ 第 8 站如实报告"开环"。**
`[stop] 反馈回流：未完成回流` —— CLI 是单次运行，没有会话状态可回流。
按 0.3-I1「没有回流，系统就是开环的」，它**明说**了，而不是假装完成。

**⑤ 自检抓到了两个真问题。**

- `0.8-C1` 报出"保持API兼容"这个关键约束在输出中没体现——**这是真实缺陷**，
  因为上面的输出行只是把用户原话回显了一遍，确实没有回应这个约束。
- `0.8-C4` 报出会话未回流。

> 注意：自检**没有**为了让报告好看而放行。这正印证了 0.8 的定位——
> 「先过闸，再断言」。一个永远通过的自检等于没有自检。

## 在代码里补上回流

```python
from collab_charter import Charter, Session

s = Session(Charter.load())
out = s.handle("帮我把这个模块重构成可测试的结构", constraints=["保持API兼容"], has_multi_step_plan=True)

# 0.3 第 8 站：把值得沉淀的流写回记忆
s.reflow(deposit=out.flows)

# 再跑一次，C4 就会通过
out2 = s.handle("再确认一次约束", constraints=["保持API兼容"])
print(out2.selfcheck.passed)
```
