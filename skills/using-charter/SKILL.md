# 使用协作宪章

<SUBAGENT-STOP>
如果你是被派来执行具体任务的子代理，跳过本技能。
</SUBAGENT-STOP>

<EXTREMELY-IMPORTANT>
只要你认为某个技能或条款有 1% 的可能适用于当前动作，就必须先查验它。

技能适用于你的任务时，你没有选择权——必须使用它。

这不是可协商项，你无法用「这次比较特殊」说服自己绕开。
</EXTREMELY-IMPORTANT>

## 规则

**在任何回应或动作之前，先查验技能与条款** —— 包括澄清性提问、翻代码、读文件。
查验后若发现不适用，可以不用。

顺序：先 `using-charter`（本技能），再按需 `info-flow-protocol`，领域任务再叠加
`feature-cluster-syntax` / `deep-research`。

## 何时调用哪个

| 场景 | 先调用 |
|---|---|
| 「帮我做 X」「我们来搭个东西」 | `info-flow-protocol`（确立走全量还是快速通道） |
| 图像提示词创作、优化、诊断 | `feature-cluster-syntax` |
| 需要深度调研、多方核实 | `deep-research` |
| 要新增或修改本仓库的技能 | `authoring-skills` |
| 会话刚开始、要确认哪些条款可执行 | MCP 工具 `charter_receipt` |

## 红旗自查

出现下列念头时，说明你正在合理化，停下来：

| 念头 | 事实 |
|---|---|
| 「这只是个简单问题」 | 问题也是任务，先查验。 |
| 「我需要先了解上下文」 | 查验在提问之前。 |
| 「我先翻下文件」 | 技能会告诉你该怎么翻。 |
| 「我记住这个技能了」 | 技能会演进，读当前版本。 |
| 「这不算任务」 | 动作即任务。 |
| 「技能太重了」 | 简单的事会变复杂，用它。 |
| 「我先做这一件事」 | 做之前先查验。 |

## 平台适配

若你的宿主在此列表中，读对应文件了解工具名映射：

- 通用映射表：`harnesses/tool-mapping.md`
- 无 MCP 能力：用 `python3 -m collab_charter.cli <子命令>` 降级
- 无本地文件访问：按 6-R4 请用户粘贴内容，显式说明能力缺失

## 用户指令优先

用户指令（AGENTS.md / GEMINI.md / 直接要求）优先于技能，技能优先于默认行为。
只有用户明确要求时，才跳过某个技能流程。无法满足某条宪章时，首次响应必须
显式列出该条与降级方案，之后不再重复（7-R4）——**不允许静默忽略**。
