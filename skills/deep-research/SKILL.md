# 深度研究

把模糊需求拆成可验证的步骤，通过多路径推理、多信源交叉验证、**对抗性校验**，
输出有据可依、逻辑自洽的结论。

核心原则：**思考先行、证据说话、对抗验证、持续自检。**

## 检索五阶

### 阶段 1 · 查询解析
提取核心实体、时间、地域、事件类型；识别明确需求与**潜在假设**；标记查询自带的
预设立场（后续隔离）；生成 3–5 组检索关键词。

### 阶段 2 · 多维度检索

| 层级 | 来源类型 | 适用 |
|---|---|---|
| 公开层 | 搜索引擎、官方发布、学术库 | 事实查询、背景信息 |
| 半公开层 | 行业论坛、专业社群、白皮书 | 深度洞察、实际经验 |
| 推理层 | 基于已知事实的逻辑推导 | 信息不足时的合理推断（**必须标注「推测」**） |

### 阶段 3 · 信源评估与交叉验证

| 等级 | 类型 | 可信度 | 使用规则 |
|---|---|---|---|
| A | 官方发布、学术期刊、政府文件 | 90%+ | 优先作为基准 |
| B | 知名媒体、行业顶级协会 | 70–90% | 需甄别立场 |
| C | 自媒体、博客、论坛 | 30–70% | 仅作线索 |
| D | 匿名来源、情绪化内容 | <30% | 仅识别异常 |

**关键事实至少需 2 个独立信源确认，否则标注「待验证」。**

### 阶段 4 · 证据链构建
按时间线或逻辑线梳理关键事实；严格区分四态：✅确证事实 / 🟡高度可能 / 🔵推测猜想 /
🔴存在争议；识别逻辑跳跃、时间错位、利益诱导。

### 阶段 5 · 证据溯源账本
每个关键结论绑定来源 ID，结论与来源一一可查：

```
[E1] 来源：xxx | 时间：2026-xx-xx | 摘要：xxx
[E2] 来源：xxx | 时间：2026-xx-xx | 摘要：xxx
```

## 对抗验证（核心，不可跳过）

对**每一个重要结论**，主动搜索反面：

- ❌ **反面证据**：有没有反对这个观点的研究/数据？
- ❌ **局限性**：这个结论的适用边界是什么？
- ❌ **失败案例**：有没有人试过失败了？为什么？
- ❌ **竞争理论**：有没有其他解释？
- ❌ **时效性**：这个信息过时了吗？

### 三态结论输出

| 状态 | 含义 | 标注 |
|---|---|---|
| 确认 | 多信源交叉验证一致，无明显反例 | ✅ 已验证 |
| 可疑 | 证据不足，存在矛盾 | 🟡 待验证 |
| 冲突 | 多方证据矛盾，各执一词 | ⚔️ 存在争议 |

**绝对禁止**：把推测写成事实，把单一来源写成定论。

## 输出模式（自适应）

**标准模式**（默认）
```
【核心结论】1–3 句直击本质
【原理说明】底层逻辑是什么
【实操建议】要行动的话怎么做
```

**深度模式**（L3/L4、决策规划、系统设计）
```
【核心结论】1–3 句精准答案
【权威支撑】引用来源（E1/E2/E3…），标注出处
【底层逻辑】拆解本质，给出可复用框架
【落地路径】分步方案，每步有目标与验收标准
【对抗验证】反例、局限、风险点
【风险与补充】不确定性、争议点、备选方案
```

## 硬规则

1. 所有事实性陈述必须有依据，不编造。
2. 回答必须承接上下文，不重复提问。
3. 始终以解决用户诉求为核心，**先给结论**。
4. 学术争议必须呈现多方观点。
5. **涉及数字计算必须用工具，不心算。**
6. 实时信息必须优先检索。

## 常用思考框架（按需调用，不堆砌）

第一性原理（拆到最基本事实重新推导）· MECE（相互独立完全穷尽）· 金字塔原理（结论先行）·
SWOT · 5W2H · PDCA · 成本收益分析 · 费曼学习法（用最简单的语言解释）· 因果回路图（正负反馈回路）。
