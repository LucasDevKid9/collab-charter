# 六大功能簇 · 四层模型 · 媒介链路

> 来源：《模块化特征簇标记语法》第 2、3、6 章。本文件是 `feature-cluster-syntax`
> 技能的延伸参考；主文件保持精简，细节放这里。

## 一、六大功能簇（2.1）

分类的**封闭集**——一切分析、挖掘、优化的坐标基准。

### 1. 主体实体簇
画面主体与构图取景。判定要点：主体是什么、取景范围、朝向与姿态是否明确。
**这一层缺失或薄弱，后续所有风格、质感、氛围词条都会发生向量漂移。**

### 2. 原生绘制属性簇
绘制技法与美术属性：平涂、硬边缘、笔触、描边、图层叠加方式。

### 3. 色彩系统簇
色深（16-bit indexed color）、抖动（Bayer dithering）、套印精度、调色倾向
（偏色/褪色/高溢色）、有限色板。

### 4. 媒介采集痕迹簇
「采集—输出—存档」链路上的痕迹：扫描线、屏摄、噪点、颗粒、压缩伪影、截图。

### 5. 图像畸变 / 图层结构簇
损伤失真与图层关系：顶点抖动、仿射纹理映射扭曲、色差、抠图伪影、图层挤压、
排版对主体的覆盖关系。

### 6. 光影氛围 / 画幅簇
光影结构（平光、低动态范围、高对比度）、氛围、画幅比例。

**排布顺序建议（隐性权重梯度）**：
主体实体 → 原生绘制 → 色彩系统 → 媒介采集 → 畸变图层 → 光影氛围。

## 二、词条四重属性（2.2）

每个词条在分析时必须同时给出：
功能簇归属 · 映射等级 · 同源链路 · 歧义度。

## 三、词条类型学（2.3）

| 类型 | 定义 | 示例 | 权重与数量规则 |
|---|---|---|---|
| **实体视觉词条** | 直接对应可成像特征 | 低分辨率、反光唇釉、暗苔绿背景 | 高映射，优先使用，承担主干，权重可 >1.0 |
| **抽象概念词条** | 表达主题、情绪、哲学感受 | 存在主义焦虑、宿命感 | 低映射，仅作气质约束，**数量必须少于实体视觉词条**，权重统一 <1.0 |
| **技术参数词条** | 画幅、比例、ISO 等约束 | 4:3、16:9、240p | 高确定性，约束边界，不作画面主体 |

## 四、创作四层设计模型（3）

思考顺序**不可逆**，从底层锚点向上逐层搭建。

### 第一层：核心载体锚点
两个根基：**画面主体是什么** + **图像原生媒介载体是什么**。置于全文最前端。

> 判定规则：主体实体词缺失、取景范围未定义、媒介载体未锁定时，第一层不成立，
> 不得进入下一层。

### 第二层：风格域选择与数量法则
- 主风格域 ≤ 2（高权重）
- 次要风格域 ≤ 1（低权重，作调味）
- **超过三个强风格域即构成高风险风格撕裂**，各风格互相争夺主导权，输出不可控。

风格域必须与载体锚点兼容：载体锚点决定风格域是否可能成立，风格域不得否定载体锚点。

### 第三层：媒介链路特征挂载
链路：**创作/拍摄 → 数字化 → 显示/记录 → 转录存档**。

所有质感词条必须归属链路中的某一环节，**不得凭空挑选**。

> 异源叠加会产生潜在冲突：Agfacolor 胶片色彩属胶片摄影链路，Hi8 质感属模拟
> 磁带录像链路，二者异源，同时挂载出现载体矛盾。跨链路叠加必须标记风险，
> 并通过权重制衡。

### 第四层：抽象氛围词条挂载
视觉映射能力弱，只能作顶层微调。数量少于实体视觉词条，统一降权，不得作主干。
抽象词条过多会挤占实体特征的向量权重，造成画面空洞、结果不稳定。

### 权重与顺序逻辑（3.5）

| 层 | 权重区间 |
|---|---|
| 第一层 核心载体锚点 | 1.2 – 1.4 |
| 第二层 主风格域 | 1.1 – 1.3 |
| 第三层 质感特征 | 0.8 – 1.1 |
| 第四层 抽象氛围 | 0.5 – 0.8 |

**顺序即隐性权重**：靠前簇获得更高向量优先级。权重与顺序必须一致，不得出现
顺序靠前而权重被压低的主体词条。

## 五、媒介链路溯源法（6.1）

第一步固定动作：**还原目标图像/风格的完整生成链路**。

| 链路环节 | 对应候选词条类别 | 归属簇 |
|---|---|---|
| 创作 / 绘制 | 绘制技法 | 原生绘制 |
| 数字化采集 | 色深、抖动、索引色 | 色彩系统 |
| 硬件输出显示 | 显示设备、扫描线 | 媒介采集 |
| 转录 / 截图 / 压缩存档 | 压缩伪影、几何变形 | 畸变图层 |

> 判定规则：任何失真词条、质感词条必须能归属到链路的某一环节；**无法归属的
> 词条列为离链词条**，离链词条仅可作氛围调味，不得承担质感主责。

## 六、跨领域知识库调度（6.2）

挖掘词库时必须**并行调度多个领域**，交叉提取候选词条，不得只依赖单一领域：
美术史 · 摄影技术 · 显示硬件 · 编码压缩 · 平面设计 · 亚文化流派。

调度方式：针对给定风格主题并行检索，提取**全部**候选词条后进入评估，
**禁止在检索阶段自行过滤**（第 11 章禁止静默过滤）。

## 七、臆想察觉与联想推演（6.5）

从给定素材出发主动发现未被明示的关联方向：

- **概念联想**：核心概念向相邻概念域扩展（「社交媒体焦虑」→ 算法、流量、数据、屏幕、过曝、遗忘）
- **视觉转译**：抽象概念转译为具体视觉特征（「宿命感」→ 被强编码的构图、压迫性排版、直视镜头的凝视）
- **媒介反推**：从预期成品形态反推生成链路（「复古网络艺术海报」→ 截图→压缩→锐化→排版叠加→套印）
- **跨域映射**：不同领域间建立类比（录像失真 ↔ 记忆失真）

臆想察觉产出的候选词条**一律标记为「待验证」**，进入精确筛选，不得直接入词库。

## 八、词条归档与分级（6.7）

通过筛选的词条按六大簇归档，每条登记：功能簇 · 映射等级 · 同源链路 · 歧义度 ·
推荐权重区间 · 组合注意事项。

分为三级：**核心词条**（强关联、高映射，构成质感主干）· **增强词条**（中等映射，
补充细节）· **调味词条**（抽象氛围，低权重）。词库随实践持续更新，实证结论写回。
