## 案例一：PC-98 复古视觉小说立绘（分支 A · 媒介复刻型）

### 提示词全文

```text
PC-98 era visual novel sprite（PC-98时代视觉小说立绘）, 古早立绘，半身像，赛璐璐平涂，
16-bit indexed color，Bayer dithering，硬边缘，色彩套印不准，透明背景抠图伪影，
对话框 UI (Dialogue box UI), 近距离随手拍，特写镜头 (Close-up)，CRT 扫描线 (CRT scanlines),
色差 (Chromatic aberration), 极度压缩伪影，极低分辨率 (240p)，全景深 (Deep focus),
原始未处理截图，低动态范围 (Low dynamic range), 平光，全片ISO为同一固定值，固定高ISO，
明显数字噪点，去除复杂光影，无情绪 (Deadpan), 无机质氛围，自动白平衡失误，发灰、偏色、褪色，
欠曝 (Underexposed), 顶点抖动 (Vertex jitter), 仿射纹理映射扭曲 (Affine texture warping),
原始比例，4:3
```

### 关键解读

- **分支定性**：纯特征短句簇，媒介复刻型
- **底层锚点**：PC-98 视觉小说立绘为主体，PC-98 计算机图像为媒介载体
- **链路**：手绘立绘 → 16-bit 索引色数字化 → PC-98 输出至 CRT 显示 → 截图/压缩存档；各失真词条均归属链路环节
- **冲突识别**：`透明背景抠图伪影`（素材导出痕迹）与 `近距离随手拍`/`高ISO噪点`（相机采集痕迹）属**异源链路**，现实不自然共存，须权重制衡
- **高风险词条**：`顶点抖动`、`仿射纹理映射扭曲`、`全片ISO为同一固定值`——专业术语映射不稳定，易泛化为笼统抖动与噪点
- **优化方向**：主体与对话框 UI 前置强化；专业术语降级或拆解；失真词条统一降权，保留 `16-bit indexed color`、`Bayer dithering`、`硬边缘` 为核心质感

### fcslint 实测

```bash
PYTHONPATH=tools python3 -m fcslint "<上面的提示词>"
# → 控制力量化 92.1/100（A 可控）
# → FCS011：媒介采集 的首次出现位置晚于更高层级的簇（畸变图层先于媒介采集出现）
# → 优化稿：主体锚点补权 1.2，抽象词条（无情绪、无机质氛围）降权 0.6，按四层重排
```

## 案例二：Hi8 私影像楚原 Cult 武侠（分支 B · 风格叠合实验）

### 提示词全文

```text
(上世纪80-90年代末的Hi8机分辨率质感风格:1.4)，(Agfacolor胶片色阶浸染，时代印痕:0.8)，
Lartigue的私密瞬间，近窥视主义下畸变，(私影像cult风:1.3)，低保真，光感漫射，带着微微颗粒感，
禁噪点，弱介质遮挡且朦胧迷幻，柔光消硬影，高光溢柔边，色彩弥散渐变柔和，
彩色边缘人物气质代表可爱甜腻和诡秘邪魅的Cult片质感张力，低分辨率，轻微高溢色，
熟悉但感觉不对氛围感，无厘头情色谐谑，室内场景光线不匀且有轻微曝光，场景局促，
彻底低俗后的自由、没有底线的童真，畸变下的构图法则与视觉引导耦合，
未经刻意排练随心一手抓拍效果，穿着武侠Cult角色服装，塑料感美学，衣服装饰材质柔光流变，
受困的戏剧感，挑衅性的媚俗，楚原奇情武侠，人工布景象征美学，对镜头做出专注认真可笑，
似半醒半睡间的视野，假装窥视无意中私密记录，有点模糊，(后超现实主义:0.6)，随机种子，16:9
```

### 关键解读

- **分支定性**：风格叠合实验簇，多风格域融合实验
- **底层锚点**：身着武侠 Cult 戏服的人物为主体，80–90 年代 Hi8 模拟录像为媒介载体
- **风格域检查**：主风格域两个（Hi8 私影像、楚原奇情武侠）+ 次要风格域一个（后超现实主义 0.6），**恰处数量法则上限**
- **冲突识别**：
  - **直接语义冲突**：`带着微微颗粒感` 与 `禁噪点` 字面互斥，**必须取舍**
  - **跨域逻辑冲突**：Agfacolor 胶片链路与 Hi8 录像链路异源；楚原舞台化与随手偷拍观看机制矛盾——属可控风险叠加
- **抽象氛围词占比偏高**：可爱甜腻/诡秘邪魅、无底线童真、熟悉但感觉不对等视觉映射弱，挤占向量空间
- **无效词条**：`随机种子` 为无效技术参数，应移除
- **优化方向**：主体定义补充（单人女性角色、半身近景）；抽象情绪词降权；删除直接冲突词之一；16:9 画幅保留

### fcslint 实测（节选版）

```bash
PYTHONPATH=tools python3 -m fcslint "(上世纪80-90年代末的Hi8机分辨率质感风格:1.4)，(Agfacolor胶片色阶浸染，时代印痕:0.8)，(私影像cult风:1.3)，低保真，光感漫射，带着微微颗粒感，禁噪点，低分辨率，随机种子，有点模糊，16:9"
# → 控制力量化 42.0/100（D 不可控）
# → ✗ FCS004 直接语义冲突：「颗粒感」与「禁噪点」字面互斥
# → ✗ FCS008 缺少第一层「核心载体锚点」
# → ! FCS007 无效技术参数：随机种子
# → ! FCS009 跨域逻辑冲突：「Agfacolor」与「Hi8」异源
# → i FCS010 权重梯度偏离：Hi8 质感 1.4 超出媒介采集区间 [0.8, 1.1]
```

> 注意：规范原文把 Hi8 给了 1.4 的高权重——这是**创作者的有意选择**（把它当风格主干）。
> 工具的提示是「与顺序形成的隐性权重可能不一致」，属于提醒而非判决；按第 11 章
> 禁止项 5，不得据此抹除创作者意图。

## 案例三：2020 年代数字废土与网络核艺术（分支 C · 概念驱动）

### 提示词全文（节选结构）

```text
2020年代数字废土与网络核艺术，社交媒体焦虑与Y2K排版过度美学，高饱和荧光白、暗苔绿与肉粉色撞色，
3:4竖版，极度特写面部局部（眼部与唇部）。[……约 800 字概念论述……]
依恋发生在数据增长的瞬间，失去发生在被算法遗忘的刹那；明知这是一场为社交媒体制造的虚假幻觉，
仍主动沉溺在这过度曝光的眩晕中，一种被命运死死按在屏幕前、被强行编码的宿命感。
[……] 采用荧光白、暗苔绿、肉粉色、深墨黑四色有限套印，局部使用冷白作为屏幕与唇釉的高光反射。
[……] 禁止全图模糊，禁止写实摄影质感，禁止额外新增色彩，禁止出现真实可读的完整句子或品牌，
禁止明亮商业广告感，禁止出现任何真实品牌名称、真实人名或可读的具体文字。3:4
```

### 关键解读

- **分支定性**：概念驱动混合体，概念表达型创作
- **结构分离**（分支 C 的必经第一步）：
  - **概念主题层**：数字身份过载、审美疲劳、存在主义焦虑、宿命感、过期焦虑
  - **可成像视觉特征层**：眼部与唇部特写、瞳孔图案、长睫毛、反光唇釉与指甲、四色套印、高压缩 JPEG 伪影、过度锐化、电子噪点、拥挤排版、虚假条形码
- **概念层处理**：全部为低映射抽象词条，仅作气质约束，**不得直接成像**；视觉特征层承担画面主干
- **冲突识别**：
  - `极度拥挤排版` 与 `不覆盖核心瞳孔` 之间存在**空间约束张力**，须显式声明「排版环绕主体但不覆盖核心部位」
  - `高压缩伪影` 与 `主体极度清晰` 之间须以「**主体清晰、背景与排版带压缩感**」区分区域
- **风险判定**：概念论述过长会稀释视觉特征权重；排版元素易生成真实可读文字，违反禁止项
- **优化方向**：视觉特征层前置，概念层降为低权重氛围词条；排版与主体的空间关系显式化；**禁止项分散到相关特征附近**（而不是全堆在末尾）

## 跨案例的共性结论

| 观察 | 结论 |
|---|---|
| 三个案例都出现「链路异源」 | 跨域冲突是高频风险，需常态化检查（`FCS009`） |
| 两个案例包含无效技术参数或弱势锚点 | 冗余过滤与锚点检查应作为固定动作，而非可选 |
| 分支 C 的概念层最易被误当成图像特征 | 分析前必须先做「概念层 / 视觉层」分离 |
| 创作者的有意高权重不一定是错误 | 工具提示与规范判定都要与创作者意图核对（禁止项 5） |
