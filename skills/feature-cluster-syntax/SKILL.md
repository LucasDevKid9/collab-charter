# 模块化特征簇标记语法

面向图像生成模型编码器的标记语言：**以逗号分隔的特征词条为基本单元，按语义
领域聚类排布，靠词条顺序与权重承担隐性锚定**。它不是自然语言，不靠主谓宾与
从句构建语义。

核心认知一句话：**实例可变，体系恒常。** 提示词文本是实例，可以增删改；词条
分类规则、簇组织逻辑、四层设计模型恒常，不得另起体系。

## 两件事必须并行做（第 11 章禁止二选一）

1. **诊断解构**（5.1）：不改原文，逐条归类、评估映射、找冲突。
2. **簇结构保留优化**（5.2）：只做重排、增删、调权，**禁止改写为自然叙事长句**。

## 六大功能簇（2.1，封闭集）

任何词条必须可归入且仅归入其中之一：

| 簇 | 内容 | 排布位置 |
|---|---|---|
| 主体实体 | 画面主体、构图取景 | 最前 |
| 原生绘制 | 绘制技法、美术属性 | ↓ |
| 色彩系统 | 色深、抖动、套印、调色 | ↓ |
| 媒介采集 | 采集—输出—存档链路上的痕迹 | ↓ |
| 畸变图层 | 损伤失真、图层结构 | ↓ |
| 光影氛围 | 光影、氛围、画幅 | 末尾 |

顺序即隐性权重：靠前簇获得更高向量优先级。

## 四层设计模型（3，顺序不可逆）

```
第一层 核心载体锚点   主体是什么 + 原生媒介是什么    权重 1.2–1.4
第二层 风格域选择     主风格≤2 + 次要风格≤1          权重 1.1–1.3
第三层 媒介链路特征   创作→数字化→显示→存档，各环节对应词条   0.8–1.1
第四层 抽象氛围       情绪/哲学感受，只能微调          0.5–0.8
```

**风格域超过三个即构成高风险风格撕裂**（3.2）。**抽象词条数量必须少于实体
视觉词条**（3.4），否则挤占向量空间，画面空洞。

## 三条最容易踩的坑

1. **直接语义冲突必须删除其一**（8.3）：如「颗粒感」与「禁噪点」字面互斥，禁止交由模型自行理解。
2. **跨域逻辑冲突要标记不要删除**（8.3）：如 Agfacolor 胶片链路与 Hi8 录像链路异源，
   属可控风险叠加，靠权重制衡与簇隔离管理。
3. **混淆两件事是范式失格**（第 11 章）：词条在现实世界的含义 ≠ 词条在 CLIP 向量空间的映射效果。

## 用工具，别靠感觉

```bash
# 诊断 + 优化建议（人类可读）
PYTHONPATH=tools python3 -m fcslint "<提示词>"

# 结构化输出，字段可供程序消费
PYTHONPATH=tools python3 -m fcslint --json "<提示词>"
```

Agent 环境下直接调 MCP 工具 `fcslint_analyze`，返回六大簇归类、权重梯度偏离、
冲突清单、控制力量化评分（0–100）与同范式优化稿。

**注意**：工具只覆盖词库中已登记的词条。遇到 `FCS001`（未归类）时不要跳过——
那正是需要你人工判定并补进 `knowledge/lexicon.yaml` 的地方（6.6 要求给出
保留或淘汰理由，禁止静默过滤）。
